## 📖 Overview

**CyberSec Academy** is a complete front-end website for a cyber security training institute. It's built with pure **HTML, CSS, and vanilla JavaScript** — no frameworks, no build tools, no dependencies. Just open the file and it works.

The site features a **neon-terminal design language** — green glow accents, scanline effects, monospace typography, and hacker-style UI elements — designed to appeal to aspiring ethical hackers and security enthusiasts.
