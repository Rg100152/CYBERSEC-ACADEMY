// WHAT YOU WILL LEARN

Course Modules

Eight progressive modules designed to take you from fundamentals to advanced offensive security.

01
Month 1 · Foundation

Networking & OS Fundamentals

Build a rock-solid foundation in computer networking and operating systems — the backbone of every cyber security career. Understand how data travels, how devices communicate, and how to navigate Linux like a pro.

  • OSI & TCP/IP Models
  • IP Addressing & Subnetting
  • DNS, DHCP, HTTP/HTTPS
  • Routing & Switching Basics
  • Linux Command Line Mastery
  • File Permissions & Users
  • Windows OS Architecture
  • Virtualization (VMware, VirtualBox)
Wireshark Kali Linux VirtualBox Cisco Packet Tracer
02
Month 2 · Security Basics

Cyber Security Essentials

Understand the threat landscape, security principles, and the mindset of an attacker and defender. Learn cryptography fundamentals and how real-world attacks unfold.

  • CIA Triad & Security Principles
  • Threat Actors & Attack Vectors
  • Malware Types & Analysis
  • Cryptography (Symmetric/Asymmetric)
  • Hashing & Digital Signatures
  • PKI & SSL/TLS
  • Social Engineering Attacks
  • Incident Response Basics
OpenSSL HashCat John the Ripper
03
Month 3 · Recon

Reconnaissance & Footprinting

Information gathering is 80% of hacking. Learn passive and active reconnaissance, OSINT techniques, and how to map a target's entire digital footprint.

  • Passive vs Active Recon
  • Google Dorking
  • WHOIS, DNS Enumeration
  • Subdomain Enumeration
  • Email & Social Media OSINT
  • Shodan & Censys
  • Network Scanning with Nmap
  • Vulnerability Scanning
Nmap Shodan Maltego theHarvester Sublist3r

Month 4 · Offensive

System Hacking & Exploitation

Step into the attacker's shoes. Learn password cracking, privilege escalation, malware deployment, and how to exploit vulnerable systems in controlled lab environments.

  • Password Cracking Techniques
  • Privilege Escalation (Linux/Windows)
  • Metasploit Framework
  • Payload Generation
  • Persistence & Backdoors
  • Covering Tracks
  • Buffer Overflow Basics
  • Post-Exploitation
Metasploit msfvenom Hydra LinPEAS WinPEAS
05
Month 5 · Web Security

Web Application Penetration Testing

The most in-demand skill in cyber security. Master the OWASP Top 10, manual testing with Burp Suite, and how to find and exploit real web vulnerabilities.

  • OWASP Top 10 Deep Dive
  • SQL Injection (Manual + Automated)
  • Cross-Site Scripting (XSS)
  • CSRF & SSRF
  • IDOR & Broken Access Control
  • File Upload Vulnerabilities
  • Authentication & Session Flaws
  • API Security Testing
Burp Suite OWASP ZAP sqlmap Postman FFUF
06
Month 6 · Network Security

Network & Wireless Security

Attack and defend enterprise networks. Learn packet analysis, MITM attacks, Wi-Fi cracking, firewall evasion, and how to secure network infrastructure.

  • Packet Analysis with Wireshark
  • ARP Spoofing & MITM
  • DNS Spoofing
  • Wi-Fi Security (WPA/WPA2/WPA3)
  • Evil Twin & Rogue AP
  • Firewall & IDS/IPS Evasion
  • VPN & Tunneling
  • Network Hardening
Aircrack-ng Bettercap Wireshark Ettercap

Month 7 · Cloud & DevOps

Cloud Security & DevSecOps

Modern infrastructure lives in the cloud. Learn AWS/Azure security, container security, CI/CD pipeline hardening, and how to integrate security into DevOps workflows.

  • Cloud Fundamentals (AWS/Azure)
  • IAM & Access Control
  • S3 Bucket Misconfigurations
  • Docker & Container Security
  • Kubernetes Security Basics
  • CI/CD Pipeline Security
  • Infrastructure as Code Security
  • Cloud Logging & Monitoring
AWS CLI Docker Kubernetes Terraform Trivy

Month 8 · Capstone

Bug Bounty, Reporting & CEH Prep

Put everything together. Hunt real bugs on legal platforms, write professional penetration testing reports, and prepare for the CEH certification exam with mock tests.

  • Recon Automation
  • Report Writing & CVSS Scoring
  • Client Communication
  • CEH Exam Blueprint
  • Mock Tests & Practice Labs
  • Capstone Project
  • Resume & Interview Prep

// COMMON QUESTIONS

Frequently Asked Questions

Everything you need to know before enrolling.

Do I need prior coding or IT experience?
No prior experience is required. Module 1 starts from absolute basics — networking, Linux, and OS fundamentals. If you can use a computer, you can learn cyber security with us.
Is the course live or recorded?
Both. Every module includes recorded lessons you can watch anytime, plus weekly live sessions for Q&A, doubt clearing, and hands-on labs. Recordings are available for lifetime access.
Will this prepare me for the CEH exam?
Yes. Module 8 is dedicated to CEH preparation, including blueprint coverage, mock tests, and practice labs. The course aligns with EC-Council's CEH v12 objectives. Exam voucher is not included but we provide guidance on booking.
What tools and labs will I get access to?
You'll get hands-on access to Kali Linux, Burp Suite, Metasploit, Nmap, Wireshark, Docker, AWS free tier, and a curated set of vulnerable labs (TryHackMe, HackTheBox style) for safe practice.
Is there a certificate after completion?
Yes. All plans include a verifiable Certificate of Completion from CyberSec Academy. The Elite plan also includes CEH exam voucher discounts and internship/job referrals.
What if I get stuck or need help?
You'll have access to our Discord community where instructors and alumni help daily. Pro and Elite plans include dedicated doubt-clearing sessions. Elite gets 1-on-1 weekly mentorship.
